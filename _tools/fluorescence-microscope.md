A modular epifluorescence microscope built on the OpenUC2 "LEGO-style" system
for imaging fly and moth preparations.

## OpenUC2 Fluorescence
- Customizable light path from 3D-printed "LEGO" blocks
- Epi-illumination
- GFP filter box
- Turret, lens, and XYZ stages salvaged from an old (surplus) microscope
- **Cost: ~$1350**
